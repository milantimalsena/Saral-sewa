## 📌 Overview

**Saral Sewa** is a mobile application designed to simplify access to government services in Nepal. It provides step-by-step guidance, document management, form submission, and notification features to improve citizen experience.

---

## 🚀 Features

### 🔐 Authentication
- Secure Login & Registration (JWT आधारित)
- User profile management

### 🏠 Dashboard
- Welcome interface  
- Popular services  
- Quick overview of documents & notifications  

### 📄 Services Module
- Citizenship, Passport, National ID, License, etc.
- Step-by-step process guidance  
- Required document checklist  
- Online form support  

### 📂 Document Management
- Upload documents (PDF, JPG, PNG)  
- Store document number & expiry date  
- Track document validity  

### 🔔 Notifications
- Alerts before document expiry (30 days)  
- Application updates  

### 📅 Appointment System
- Book service appointments  
- Select date & time slots  

### 👤 Profile Management
- Editable profile  
- Stored locally using SQLite  

### 📍 Office Locator
- View nearby government offices  
- Map integration (Itahari fallback)
